# Segurança

Não envie segredos, URLs privadas de sessão ou arquivos pessoais em issues e pull requests.

Para relatar uma vulnerabilidade, abra uma issue sem incluir detalhes exploráveis. O processo de recebimento de relatos privados será definido antes da publicação do repositório.

Enquanto o projeto não tiver um canal privado oficial, não há garantia de tratamento confidencial. Para problemas urgentes, aguarde a definição do canal no primeiro release público.
